# Proyecto_Tesis_RMHD_Ideas
Plataforma web de comercio electrónico para microempresas artesanales, enfocada en optimizar la gestión de producción de RMHD Ideas, una microempresa artesanal colombiana. Integra la gestión de pedidos y preórdenes bajo demanda, el seguimiento de órdenes de producción, la estimación de tiempos de entrega, las recomendaciones personalizadas de productos mediante inteligencia artificial, la predicción de demanda estacional y la automatización de comunicaciones con clientes. Incluye un catálogo de productos, carrito de compras, pagos en línea y un panel administrativo, con el objetivo de mejorar la eficiencia operativa, la planificación de la producción y la experiencia de compra.
